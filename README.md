1. Introduction
The Course Registration and Timetable System is a Java-based project used to collect and display student
course information. The system allows the user to enter the student name, number of courses, course code,
course name, day, and time. After entering the details, the program displays the registered courses in a
timetable format.
2. Problem Statement
• Managing course details manually can be difficult.
• Course information may not be organized properly.
• Students need an easy way to view their registered courses.
• Creating a timetable manually takes time.
3. Objectives
• To create a simple course registration system.
• To collect student and course details.
• To store multiple course details using an array.
• To display the registered courses in a timetable format.
• To practice Java classes, objects, arrays, loops, and methods.
4. Existing System
In the existing manual system, students may write or maintain course details manually. This can make the
information difficult to organize and update.
5. Proposed System
The proposed system uses Java to register and display course information. The user enters the required
details, and the program stores them in Course objects. Finally, all courses are displayed in a clear timetable
format.
